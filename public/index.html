MediaCord Setup Instructions

Media Player Setup

MediaCord supports multiple media players. Choose the one that works best for you:

Option 1: VLC Media Player (All Platforms)

Enable VLC's HTTP interface by adding these parameters when launching VLC:

--intf http --http-host localhost --http-port 8080 --http-password vlcpassword

Or configure via VLC Preferences:

  1. Tools → Preferences
  2. Show all settings (bottom left)
  3. Interface → Main interfaces → Check "Web"
  4. Interface → Main interfaces → Lua → Lua HTTP → Set your password

Option 2: IINA (macOS Only)

  1. Install IINA from iina.io
  2. Download the iina-status-bridge plugin
  3. Double-click the .iinaplugin file to install
  4. Restart IINA - MediaCord will automatically detect it!

Note: You can use both players! MediaCord will automatically switch between them.

Discord Application Setup

  1. Go to Discord Developer Portal
  2. Create a new application
  3. Copy the Application ID to the Client ID field in MediaCord settings
  4. Under Rich Presence → Art Assets, upload these images:
    • vlc - VLC logo
    • iina - IINA logo (optional)
    • mediacord - MediaCord logo
    • play - Play icon
    • pause - Pause icon

TMDb Setup (Optional)

MediaCord includes a shared API key, but you can use your own for better performance:

  1. Sign up at TheMovieDB
  2. Go to Settings → API → Create new API key
  3. Copy the API Key (v3 auth) to the TMDb API Key field in MediaCord settings
